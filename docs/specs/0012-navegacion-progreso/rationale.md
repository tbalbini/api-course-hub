# Decisión de continuidad del recorrido

La base visual, el inspector y la navegación ya existen. Reemplazarlos crearía diferencias entre laboratorios. Un registro complementario evita una migración destructiva de los logros de primeros principios y permite integrar los nuevos capítulos con sus condiciones de evaluación actuales.

El usuario eligió mostrar orientación y estado pendiente en las áreas futuras. No se inventan experiencias completas para cerrar navegación. El laboratorio de sistemas está siendo implementado en paralelo y se conserva.

## Organización por áreas del producto

El usuario pidió revisar la estructura inicial y continuar con la jerarquía reorganizada en `docs/scope/index.md`. La navegación adopta cinco áreas de producto y conserva las superficies anteriores dentro de ellas. Los bloques de implementación y las fases no se presentan como capítulos ni como menú. El programa mantiene el orden pedagógico del 0 al 12. En móvil se usa un selector nativo para explorar las cinco áreas con teclado sin apilar todo el currículo.
