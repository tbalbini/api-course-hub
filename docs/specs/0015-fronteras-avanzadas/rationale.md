# Decisión de fronteras avanzadas

## Context

El estudiante ya puede seguir pedidos reales y comparar modelos distribuidos. Falta conectar ese mapa con contratos binarios, runtimes, protocolos de bases de datos y herramientas propuestas por modelos. Repetir solo definiciones dejaría invisibles la representación, la validación y el lugar donde se ejecuta un efecto.

## Options considered

Un catálogo únicamente textual cubre nombres pero no comprueba mecanismos. Levantar C/Rust, PostgreSQL y un proveedor de IA agrega instalación y credenciales a experiencias esenciales. Se eligen tres experimentos locales: Wasm real y modelos explícitos de las otras fronteras, integrados con el motor existente.

## Rationale

Wasm permite observar un contrato tipado y un trap reales sin ejecutar texto editable ni instalar un compilador. Una convención binaria de juguete muestra incompatibilidad sin enseñar reglas falsas de una ABI concreta. El framing de Query permite inspeccionar longitud y entrega parcial sin fingir SQL ejecutado. Las herramientas muestran que una propuesta estructurada necesita registro, validación y permiso antes del efecto; adaptar una salida enseña evolución desde el consumidor.

Los doce temas mantienen conexiones, límites y evaluación propia. Se reutilizan las decisiones de progreso y diseño para que el alumno cambie de profundidad sin reiniciar. No se introducen dependencias ni nuevas credenciales. La preferencia de no añadir sección de referencias se conserva.
