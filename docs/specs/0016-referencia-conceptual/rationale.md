# Decisión de referencia conceptual

## Context

El contenido ya existe en capítulos y experimentos, pero localizar un término obliga a recordar dónde aparece. La referencia debe facilitar la consulta sin presentar definiciones inconexas ni perder el estado del laboratorio.

## Options considered

Un índice alfabético solo permite recorrer nombres conocidos. Un buscador remoto o CMS añadiría infraestructura sin mejorar este catálogo pequeño y editorial. Se elige búsqueda local con alias, filtros y relaciones, reutilizando taxonomía; el índice alfabético queda disponible con consulta vacía.

## Rationale

La búsqueda literal y determinista permite comprobar cada coincidencia. Los ids y URLs hacen compartible una consulta sin guardar datos operativos. Un enlace del inspector en otra pestaña conserva el experimento con el comportamiento nativo del navegador y evita otro sistema de paneles y reproducción. La guía registra qué funciona realmente y qué es un modelo. Se mantiene el diseño actual y no se añaden dependencias.
